# tg-bot — إضافة bot2.ts فوق الكود القديم

بدل حذف الكود القديم في محرّر Supabase:

1. **Add File** باسم `bot2.ts` والصق فيه محتوى `bot2.ts` (البوت الجديد كاملاً).
2. في أول `index.ts` (قبل السطر الأول) أضف:
   ```ts
   import "./bot2.ts";
   async function __oldBot() {
   ```
3. في آخر `index.ts` (بعد السطر الأخير) أضف:
   ```ts
   }
   ```
4. **Deploy updates**.

الكود القديم يصبح داخل دالة لا تُستدعى أبداً، فلا يعمل؛ والجديد في bot2.ts هو الذي يستقبل الرسائل.
للرجوع: احذف السطرين من الأول والقوس من الآخر، ثم Deploy.
